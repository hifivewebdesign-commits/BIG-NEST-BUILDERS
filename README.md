# BIG NEST BUILDERS - Official Website

> **Tagline:** YOU DREAM IT. WE BUILD IT.

Official website for **Big Nest Builders** - Bangalore, Karnataka.

## 🚀 Overview
- **Tech Stack:** PHP, HTML5, CSS3, JavaScript
- **Features:** Responsive Design, Fast Loading, Contact Forms, Hero Animations, Lightbox Gallery.

## 📁 Project Structure
- `api/` - Form processing and backend endpoints
- `assets/` - CSS stylesheets, JS scripts, fonts, and images
- `data/` - Content and data files
- `includes/` - Modular PHP components (header, footer, hero, services, etc.)
- `config.php` - Global site configuration and settings
- `index.php` - Homepage
